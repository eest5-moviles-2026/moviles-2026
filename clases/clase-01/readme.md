# Clase 01: Introducción y Herramientas
**Materia:** Desarrollo de Software para Plataformas Móviles

En esta primera clase del ciclo lectivo configuramos nuestro entorno de trabajo local en el laboratorio de la escuela y aprendimos las bases para documentar nuestros proyectos y utilizar el control de versiones.

## 📚 Materiales de Referencia:

*   👉 [**Guía Básica de Git y GitHub**](./guia-git.md): Conceptos básicos, ciclo de comandos principal (`add`, `commit`, `push`, `pull`), comandos de consola y protocolo para aulas compartidas.
*   👉 [**Guía Rápida de Markdown**](./guia-markdown.md): Cómo estructurar textos, encabezados, negritas, listas y bloques de código para documentar tus trabajos en archivos `.md`.
