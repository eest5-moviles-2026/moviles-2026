# Instrucciones de Trabajo - PC 4
**Widget Asignado:** Avisos Parroquiales (Novedades)

---

## 🛠️ Tareas a realizar en tu rama `feature-pc4`:

### 1. Desarrollar el HTML (`index.html`):
Buscá el comentario `<!-- [PC 4] AGREGÁ TU WIDGET DE AVISOS PARROQUIALES ABAJO DE ESTE COMENTARIO -->`. Debés programar allí una tarjeta que cumpla con los siguientes requisitos:
1. Una etiqueta `<section>` contenedora con las clases `widget-card` y `widget-notices`.
2. Adentro, un título `<h3>` que diga `📢 Novedades`.
3. Un párrafo `<p>` con la clase `date` que diga `Próxima Clase:`.
4. Un párrafo `<p>` con el texto del aviso: `Nivelación de JS Parte II (Objetos y Arrays). Traer ejercicios resueltos.`

### 2. Escribir los Estilos en CSS (`style.css`):
Andá al final del archivo `style.css` y escribí las reglas de diseño necesarias para tu widget:
1. Estilá la clase `.widget-notices .date` para que su fuente sea pequeña (`0.75rem`), grosor extra-negrita (`800`), en mayúsculas (`text-transform: uppercase`) y color gris suave (`var(--text-muted)`).

### 3. Registrar a tus Integrantes:
Buscá el comentario `<!-- [PC 4] Agregá tu bloque de créditos abajo de este comentario -->` en el footer. Debés crear una estructura HTML que contenga:
1. Un contenedor `<div>` con la clase `team-credits`.
2. Un título `<h4>` que diga `PC 4 - Integrantes`.
3. Una lista desordenada (`<ul>`) que contenga los nombres y apellidos reales de todos los integrantes sentados en tu computadora.

---

## 🏁 Siguiente Paso:
Cuando termines de guardar y verificar que el diseño se vea bien en tu navegador, hacé commit en tu terminal y subí la rama a GitHub como indica el paso 2 de la [`README.md`](README.md).
