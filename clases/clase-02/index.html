💻 ¿Cómo comenzar a trabajar?

  1. Creá un archivo llamado peaje.js en esta misma carpeta (clases/clase-02/).
  2. Vinculá tu archivo agregando la etiqueta de script al final del index.html.
  3. Abrí este archivo en tu navegador (usando Live Server en VS Code).
  4. Presioná F12 o hacé clic derecho y seleccioná Inspeccionar, luego andá a la pestaña Consola.
